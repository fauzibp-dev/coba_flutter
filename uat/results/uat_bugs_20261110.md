# UAT Bugs and Defects — KKMP Kerten

## DEF-030 — UAT-036 address persistence

- **Severity:** High
- **Status:** OPEN
- **Reproduction:** On physical Xiaomi `nnzxea79ayypnzzx`, open Account > Alamat
  tersimpan > Tambah. Fill `UAT_TEST`, recipient, test phone, and
  `Jl. UAT No. 1, Kerten, Laweyan, Surakarta`; press `Simpan Alamat`; reopen the
  list.
- **Expected:** The new address is listed and selectable at checkout.
- **Actual:** The form values were visible before save, but after save only the
  existing `Rumah` address remained.
- **Impact:** COD checkout requiring a verified UAT address cannot be completed.
- **Evidence:** `uat-address-form-filled.png`, `uat-address-save-attempt.png`,
  `uat-address-create-failed.png`,
  `uat036_diagnosis_and_admin_crud_20261108-1355.log`.
- **Diagnosis boundary:** Source confirms authenticated insert and parent refresh
  wiring. The available anonymous REST query returned no row but cannot prove RLS
  failure without the authenticated user JWT. Insert/RLS/backend, wrong session,
  and refresh remain unresolved; no source change was made.

## DEF-031 — REG-011 (observasi terkait, bukan eksekusi REG-011) — Flutter lifecycle assertion

- **Severity:** High
- **Status:** OPEN
- **Reproduction:** Open Super Admin > Katalog Global, create or edit a product,
  save, and observe the device.
- **Expected:** The dialog closes and the catalog refreshes without a framework
  assertion.
- **Actual:** Device displayed `Tampilan mengalami kendala` with
  `framework.dart:6281 '_dependents.isEmpty'`. The product mutation still
  completed.
- **Impact:** Admin product workflow presents a crash/error screen despite data
  persistence.
- **Evidence:** `uat-admin-product-create-form.png`,
  `uat-admin-product-edit-form.png`, and
  `uat036_diagnosis_and_admin_crud_20261108-1355.log`.
- **Diagnosis boundary:** The dialog uses `showDialog` + `StatefulBuilder` with
  asynchronous save state updates; this is a code area for investigation, not a
  confirmed root cause. `REG-011` remains `NOT RUN` in the synchronized matrix;
  this observation must not be reported as a REG-011 PASS or a completed REG-011
  failure run. No source change was made.

No new full-suite execution was performed for this final audit.

- **Severity:** Medium

## DEF-033 — Product dialog layout overflow

- **Severity:** High
- **Status:** OPEN
- **Relation:** Layout observation related to REG-006/REG-007/REG-009/REG-022;
  those regression cases were not executed as full tests.
- **Reproduction:** Open Super Admin > Katalog Global > Tambah or Edit Produk and
  inspect the dialog on the physical Xiaomi.
- **Expected:** Dialog content fits without a RenderFlex overflow.
- **Actual:** Screenshot shows the yellow-black Flutter `OVERFLOWED BY` banner.
- **Evidence:** `uat-admin-product-create-form.png`,
  `uat-admin-product-edit-form.png`.
- **Relation to DEF-031:** Separate defect. DEF-031 concerns the
  `_dependents.isEmpty` lifecycle assertion after save; DEF-033 concerns layout
  overflow in the dialog.
